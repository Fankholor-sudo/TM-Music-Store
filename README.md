# MusoHive

**An Online Music Accessories Store Built with Angular**

## About the Project

MusoHive is a web-based e-commerce application designed to provide customers with an online platform for exploring music accessories. The project focuses on delivering a modern, user-friendly shopping experience with a responsive interface and a structured approach to managing application data.

The application is built with Angular and Angular Material, with Supabase providing backend services.

## Getting Started

### Prerequisites

* Node.js
* npm or Yarn
* Supabase configuration, if required

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Fankholor-sudo/TM-Music-Store.git
   ```

2. Navigate to the project directory:

   ```bash
   cd <MusoHiveDir>
   ```

3. Install dependencies:

   ```bash
   yarn install
   ```

4. Start the development server:

   ```bash
   yarn start
   ```

5. Open the local URL displayed in your terminal, usually `http://localhost:4200`.

### Production Build

Run the following command to build the application:

```bash
yarn build
```

## Backend Configuration

MusoHive uses Supabase for backend integration. Configure the required Supabase project URL and public client key using the project's existing environment configuration.

Never commit private keys, service-role keys, or other secrets to the repository.

## Deployment

The application is deployed through Vercel. To deploy your own version, connect the GitHub repository to Vercel and configure the appropriate build settings and environment variables.
